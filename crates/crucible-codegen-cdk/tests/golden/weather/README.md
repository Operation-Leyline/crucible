# @example/weather-cdk

Generated CDK constructs for `example#Weather`. Supply the service token of an existing provider that implements the configured resource contract. This package does not create a provider or implement resource lifecycle operations.

Run `npm install` and `npm run build` to compile the jsii assembly. Run `npm run package` to package configured language targets. Node.js is required by jsii consumers.

Model constraints are checked for concrete values. Deployment-time tokens are checked by the provider. Replacement and deletion behavior belong to that provider; immutable documentation does not enforce replacement.
