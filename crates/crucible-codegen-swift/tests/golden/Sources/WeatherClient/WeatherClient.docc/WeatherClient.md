# ``WeatherClient``

The Swift client for the Weather API (`example.weather#Weather`), generated by Crucible from the service's model.

## Overview

Create one ``WeatherClient`` and share it; every operation is an `async` method taking its input model and returning its output model.

```swift
import Foundation
import WeatherClient

let client = try WeatherClient(ClientConfig(token: { ProcessInfo.processInfo.environment["WEATHER_TOKEN"] }))
```
